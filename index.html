Frequently asked questions

Where is my data stored?

In the browser version, everything lives in your browser's local storage — nothing is sent to a server. In the desktop version, it's stored in a local file on your device, with an optional folder-sync feature you control.

Is an account required?

No. Both versions work fully without signing up for anything.

Is there a Windows version?

Yes — the desktop app is built for both macOS and Windows.

Can I import data from a CSV?

Yes, both versions support CSV import and export for clients, content, and invoices.

Is the web version different from the desktop version?

They're the same app. The desktop version adds offline use and optional folder sync; everything else works identically.

What happens if I clear my browser data?

The browser version's data would be cleared along with it — export a CSV backup first if you're about to do that, or switch to the desktop app for local-file storage.

Can I use it offline?

The desktop app works fully offline. The browser version needs to load once, then works offline until you close the tab (it doesn't currently work as an installable offline PWA).
